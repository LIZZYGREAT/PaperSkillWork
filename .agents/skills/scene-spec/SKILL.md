# Legacy Scene Specification

This skill applies only when maintaining an existing v1/v2 paper that already depends on `design/scenes/` specifications. Do not create scene-spec documents for new Workflow v3 papers. For new work, create one `design/implementation-plan.md` after the learning spine; see `.agents/skills/implementation-plan/SKILL.md`.

Do not rewrite existing per-paper scene files as part of a macro-workflow update.
