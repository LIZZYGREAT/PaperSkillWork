# Reusable Kit 视觉语言

Kit 统一文字、图元与状态的视觉语言；每篇论文根据教学目标安排构图、数据和计算。工作流使用入口见 [Reusable Kit](../docs/REUSABLE-KIT.md)，资产、成熟度与源码路径以 [Registry](registry.yaml) 为准。

## 样式真源

- [kit.css](foundation/styles/kit.css) 定义基础颜色、语义角色、字体、字号层级、间距与通用组件外观；实际 token 值以源码为准。
- [editorial.css](foundation/styles/editorial.css) 提供可选的标题、引导、公式、旁注和图文组合类，不是整页模板。
- [visual-parts.css](foundation/visual-parts/visual-parts.css) 与 [mini-network-glyph.css](foundation/neural-network/mini-network-glyph.css) 分别拥有小件和网络的完整默认外观。局部主题通过已有 token 调整，不用 Gallery override 修补公共部件。

## 色彩、层级与留白

暖白画布、浅色图面、深色正文与有限的绿/暖橙强调构成基础语言。弱线分隔、强线连接明确对象；用留白、轴线、标题与正文层级组织阅读，只有真实分组才增加表面，不把所有内容包成同样的卡片。

正文使用系统无衬线及中文回退，数学使用数学字体与真实上下标/分数布局，数值使用便于比较的等宽或表格数字。标题、正文、辅助说明、图标注和符号各用对应角色；不要以缩小语义文字、省略号或裁切挤入固定容器。大标题用于建立入口，不在每一节重复。

冻结、可训练、目标、更新和聚焦通过语义 token、文字及线型/形状共同表达，不能只靠颜色区分。键盘焦点与当前选中是不同状态。

## 数值、图形与连接

带符号向量和响应条共享正/负填充与描边规则，明确零点与尺度；显示精度由场景合理格式化，真实计算保留精度。分数、概率、训练响应与最终预测的含义由调用方负责，绘图组件不推断算法。

连接必须声明对象、方向和类型。数据、控制、梯度、参照关系使用相应线型；箭头端点与标签须对应真实对象，不能用含混的字符箭头代替空间关系。网络聚焦只改变强调，保留拓扑、ID、坐标与模型身份。密度调整可改变呈现尺度，不能改变对象归属或计算含义。

## 组件与场景的职责

资产拥有必需 TSX/CSS 和默认外观；场景拥有输入、状态、计算、布局、解释和教学边界。多个视图从同一权威状态派生；时间线只在拥有者调用一次 Hook，进度是教学揭示时间，不是假装真实训练时间。

使用匹配的 [Recipe](recipes/) 或 [完整示例包](examples/) 与 Registry 精确闭包。Gallery 负责发现、展示和交互预览；独立副本不能依赖其布局 CSS。通用外观缺陷修资产，论文特化构图留在论文中，保留键盘、触屏和 reduced-motion 能力。

## 预览与验收

[Demo 使用说明](demo/README.md) 提供 Gallery、Lab 与场景入口；[R4 复现入口](validation/README.md) 提供独立复制场景，其当前结果以 [R4 报告](validation/r4/REPORT.md) 为准。日常浏览器范围按唯一的 [Visual QA 规范](../docs/VISUAL_QA.md) 执行：普通窗口布局 1440×900、全屏尺度布局 1920×1080；后者是模拟，真实 F11 需单独实测。移动视觉检查仅按该规范的专项触发条件运行。

当前 Gallery 默认采用用户选定的 B 开场构图；这项构图选择不等于逐项批准资产。Registry 资产仍为 candidate，自动化与 Agent 视觉复核不代填人工批准。Kit V1 的能力和限制见 [工作流使用入口](../docs/REUSABLE-KIT.md#v1-当前能力与限制)。
