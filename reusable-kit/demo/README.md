# Reusable Kit local demo

The demo switches between small LwF and EWC mechanism sketches. Both use the same kit components with different paper data. The examples contain no benchmark values and are not a substitute for checking a paper's source, evidence, or conditions.

Run locally:

```powershell
npm ci
npm run dev
```

Build the standalone demo with `npm run build`. Run `npm run test:browser` to open the browser smoke checks for rendering, data-driven interactions, keyboard focusability, reduced-motion behavior, and figure zoom. The demo is a local component validation surface, not a separately deployed product.
