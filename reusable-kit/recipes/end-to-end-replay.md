# End-to-End Replay

## Purpose
Return to one persistent system view and replay the complete learning spine.

## Use When
Readers have already met the important objects and need to connect them into one causal run.

## Do Not Use When
It would introduce new unexplained components or repeat the whole lesson without a learning task.

## Minimum Interaction
Reuse the established diagram; advance through every CORE step and inspect local details inline.

## Recommended Components
`ProcessLoopExplorer`, `StickySystemView`, and `FlowStepper`.

## Teaching Goal
Help a first-time reader reconstruct the complete method from input through output and update.

## Anti-patterns
Do not create a second diagram, use decorative metaphors, or omit a CORE step from the replay.

## Example from Existing Paper
PhyAgentOS GrandLoop motivates a persistent whole-system replay; continual-learning examples can trace a task through learning and promotion of the next model.
