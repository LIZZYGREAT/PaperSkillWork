# Protocol First Results

## Purpose
Give the experiment protocol before showing numeric results.

## Use When
Dataset, task order, metric, or evaluation conditions affect how a result should be interpreted.

## Do Not Use When
The metric and conditions are irrelevant to the reader's current learning goal.

## Minimum Interaction
Present benchmark, protocol, metric, condition, result, interpretation, and limitation together.

## Recommended Components
`BenchmarkExplorer`, `DatasetCard`, and `EvidenceViewer`.

## Teaching Goal
Help readers understand what the reported number actually measures.

## Anti-patterns
Do not create a leaderboard that hides protocols or mixes incomparable metrics.

## Example from Existing Paper
Continual-learning benchmark results should retain task sequence and evaluation protocol alongside each score.
