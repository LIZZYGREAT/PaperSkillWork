## 一、交互规则与删除测试

以一条“词典校订”生活主题串联类比：词典页对应共享模型，旧批注对应旧模型响应，新词条对应新增任务。类比不是神经网络的字面过程。主要交互绘图以 Canvas 为主，Canvas 外部用可聚焦按钮、滑杆和清晰反馈；同一份 React state 同时驱动画面、数值或路径与反馈。教学示意显式标示，论文数据只用于实验对照。

每章第一个交互模块提供三项前置术语，支持悬停、键盘聚焦和点击；说明在控件行内展开，把图表向下推，避免浮层遮挡。点到其他内容、滚动或按 Escape 会收起。

### 统一类比动效与文字的逐章对齐

每章的 Canvas 类比只演示一个短动作，动作、章名和卡片文字必须指向同一个概念。动画约 1 秒完成后停在结果上，不循环；读者滚动离开时暂停，减少动态干扰。开启 reduced motion 时直接呈现最终画面。下面的映射是实现与验收依据：

| 章节 | 画面中的唯一动作 | 与文字 / 概念的对应关系 |
| --- | --- | --- |
| 1 | 铅笔在空白行写下新词条 | 增加新任务，同时看见旧条目仍留有批注 |
| 2 | 铅笔圈选一条校订路线 | 对照特征提取、微调、联合训练与 LwF 的取舍 |
| 3 | 铅笔划出旧模型在新例句旁的批注 | 旧响应由旧模型处理当前新输入而来 |
| 4 | 铅笔划出新任务专属的一栏 | 新头先独立接入；warm-up 与联合更新由旁边的步进模块展开 |
| 5 | 铅笔标亮一条相关词义 | 除最高倾向外，软目标仍保留其他类别的相对关系 |
| 6 | 铅笔用括号圈合三项校订意见 | L_old、L_new 与普通正则 R 一同进入总目标 |
| 7 | 铅笔加重旧批注的下划线 | λ_o 提高旧响应损失在目标中的相对权重，不代表准确率保证 |
| 8 | 铅笔从共享释义处画出两个分支 | 同一共享表示分别送往旧、新任务头 |
| 9 | 新例句卡片逐渐远离旧语境 | 输入分布差异可能削弱旧响应对旧任务的代表性 |
| 10 | 铅笔在核对过的结果旁画勾 | 进入已核对的实验结果与其适用范围 |

章 1 的定性对照动画持续约 1.8 秒，展示同一起点下旧任务保持与新任务适配的不同变化；章 10 每 480ms 揭示一种方法，直到表格和条形图完整显示并保持。两者都提供重播 / 重置，结束状态不会自动消失。

覆盖合同：11 个模块，包含一个双模块章节；P1/P2/P3/P4/P5/P6/P8 七类交互；温度与 `λ_o` 两章使用 P1；9 个技术 / 混合模块、至少 5 个生活 / 混合模块。单次类比动效只强化对应概念，不能替代主动操作。

## 二、逐模块实施规格

### LWF-01 · 新任务让旧模型发生什么？

- **教学目标 / 模式：**Hybrid linked views。让读者比较直接 fine-tuning 与 LwF 都能学新任务，但前者在示意图中失去更多旧任务状态。
- **初始状态与操作：**初始左右面板从同一稳定旧模型出发；按钮“开始对照”启动一次 P3 同步比较。“重置”恢复起点。无性能百分数。
- **控件 / 状态：**`running: boolean=false`；`progress:number` 从 `0` 插值到 `1`，耗时约 1.8 秒。点击开始置 `running=true`，结束后保留完整对照；“重置”恢复起点。开启 reduced motion 时直接显示最终状态。
- **Canvas：**两个等宽面板，各 560×160（窄屏纵向堆叠）：背景 → 共用词典页 / 输入卡 → fine-tuning 侧旧批注变红、LwF 侧旧响应保留绿边 → 新词条均可见。每面板至多两个短标签；其余标题在 DOM。相同起点和时间。
- **视觉状态 / 反馈：**初始“同一个旧模型，两边都还没学新词条。”结束：“两边都学新任务；LwF 多了旧响应约束，示意中的旧能力损失较小。”红表示退化，绿表示本文方法；图上值是定性状态而非测量数据。
- **证据 / 判断：**Table/Figure 1–2, PDF pp.2–3。读者能判断适配与旧任务保持是不同目标，图不暗示对任意任务都能成功。
- **无障碍 / 边界：**开始和重置为 button；Tab / Enter 可用；CSS 布局移动，Canvas 提供简短 `aria-label` 和其下方 DOM 文本等价说明；不能由动画速度代表性能。

### LWF-02 · 四种路线各自放弃什么？

- **教学目标 / 模式：**Hybrid。用同一输入卡和旧任务网络作基线对照，比较 feature extraction、fine-tuning、joint training、LwF 的数据与参数路线。
- **初始状态与操作：**初始选择 fine-tuning。四个 chip 按钮切换 `method`，每次立即改变输入可用状态、共享层颜色、旧任务状态和一句反馈。
- **控件 / 状态：**`method: 'feature'|'finetune'|'joint'|'lwf'='finetune'`。全部按钮常可用；`aria-pressed` 表明选择。
- **Canvas：**760×230；固定三栏 `旧数据` / `新数据` / `共享 CNN`。静态方块表示是否需要旧原样本，不以数值表示速度或显存；方法线段进入冻结 / 更新 / 旧响应分支。最多两个短标签，三项以内图例放 DOM。
- **编码 / 转移：**Feature extraction：共享层蓝色锁定，新头绿色训练；fine-tuning：共享层橙色更新，旧输出红色风险；joint training：旧新数据均入网、成本旁注“需旧数据”；LwF：仅新样本入网，旧模型响应作为第二路目标。
- **反馈：**对应状态分别为“旧表示不变，新任务无法专门改造共享层”“更新共享层可适配新任务，但旧任务可能退化”“能同时访问新旧监督，违反本论文的问题设定”“只用新任务样本和旧模型响应作约束”。
- **证据 / 判断：**Figure 1–2, PDF pp.2–3。任何定性优劣均加“常见取舍 / 本文设置”，不得造训练效率数字。
- **无障碍 / 边界：**chip 支持键盘；Canvas 外给四行文本摘要；移动端信息栏变为纵向两列。

### LWF-03 · 旧模型从哪里得到监督信号？

- **教学目标 / 模式：**Technical。直接辨别三种候选信号，凸显“旧模型对新输入的响应”路径。
- **初始状态与操作：**初始选择“旧样本回放”（不可用项）；切换到三个候选芯片中的任意项。禁止把不可用状态作为失效错误而没有解释。
- **控件 / 状态：**`signal: 'oldExamples'|'teacherOnNew'|'newLabel'='oldExamples'`。按钮切换；所有状态都更新路径、信号框和反馈。
- **Canvas：**760×210；左为样本输入，中为旧模型 / 新模型简图，右为 old / new target。选 `oldExamples` 显示灰色断路与“不可访问”；选 `teacherOnNew` 让同一 `X_n` 分叉到旧教师及当前模型的旧头；选 `newLabel` 只进入新头监督。节点名称主要使用 DOM legend，Canvas 内至多两个缩写。
- **反馈：**“旧图像与标签在此设定中不可用。”“LwF 用新图像跑旧模型，记录旧任务概率。”“真实标签直接监督的是新任务输出。”
- **证据 / 判断：**Figure 2(e)、method 与 Eq. (1)–(3), PDF pp.3–4。读者应能用一句话说出 `X_n → f_old → Y_o`。
- **无障碍 / 边界：**按钮取代 Canvas 点击；关系图配有 DOM 清单；窄屏输入、网络、输出垂直排列。不显示虚构 logits。

### LWF-04 · Warm-up 为什么在前？

- **教学目标 / 模式：**Life metaphor + 轻量技术路径。带读者走完真实训练阶段。
- **初始状态与操作：**显示阶段 `1/4`，按钮“下一步”和“重置”。依次为“记录旧响应 → 新头初始化 → 冻结旧参数 warm-up → 解冻并联合优化”。
- **控件 / 状态：**`step:0|1|2|3=0`；下限时“上一步” disabled，末步“下一步”改为“已完成”并 disabled；另有重置。
- **Canvas：**760×230；固定共享层、旧头、新头三个区域。阶段变更只切换边框、流线与可训练标记，节点不移动位置。Warm-up 冻结 `θ_s, θ_o`、仅新头亮起；末步三者全亮；旧响应在全部阶段来自同批 `X_n`。
- **反馈：**逐步对应：“先为当前新图像记录旧模型的旧任务概率。”“增加新任务输出参数 `θ_n`。”“Warm-up 只训练 `θ_n`；共享层与旧头冻结。”“随后联合更新 `θ_s, θ_o, θ_n`，同时匹配旧响应和新标签。”
- **证据 / 判断：**PDF pp.4–5、Figure 3。不能暗示 warm-up 是 LwF 独有或不可省略；作者指出它对 LwF 不是关键条件。
- **无障碍 / 边界：**上一步 / 下一步可由键盘操作；用文字完整表达冻结状态；Canvas 固定高不随阶段内容变。

### LWF-05 · 温度怎样改变软目标？

- **教学目标 / 模式：**Mathematical / technical。体验温度提升时类别概率分布更平滑，且目标与当前模型用相同温度变换。
- **初始状态与操作：**P1 范围滑杆 `T=1..4` 整数，默认 `T=2`，旁显示温度值。使用一组固定教学 logits `[2,1,0]` 计算 softmax(logit / T)。
- **状态：**`temperature:number=2`，有效值 `[1,2,3,4]`。滑杆 `input` 实时更新三根概率柱和三项百分比；满足总和 1（四舍五入误差除外）。
- **Canvas：**760×240；左区 raw logits 固定；右区三柱显示软化后的概率，横轴类别 A/B/C；激活栏以蓝描边显示，温度 thumb 用橙色。标题“示意分布”在 DOM，Canvas 仅短类别名 / 数值。
- **反馈：**`T=1`：“分布更尖，较小响应影响较弱。”`T=2`：“论文采用 T=2；高温会提高较小响应的相对权重。”`T=3/4`：“更平滑的教学示意；不是论文对这些温度报告的准确率。”
- **证据 / 判断：**式 (2)–(4), PDF p.4。论文选择 `T=2`；示例 logits 与柱值是教学构造，不是论文预测结果。
- **无障碍 / 边界：**范围滑杆有可见 label、当前数值和键盘可用；DOM 文本逐项报告分布；动画无持续闪烁，reduced-motion 无插值。

### LWF-06 · 总损失里的三项各做什么？

- **教学目标 / 模式：**Technical。让公式项与有效参数路径一一对应。
- **初始状态与操作：**初始选 `L_old`；三个 chip 选择新任务监督、旧响应蒸馏或正则项。
- **状态：**`lossPart:'old'|'new'|'regularizer'='old'`；更新公式高亮与对应数据箭头，不设置不在论文中的 loss 数值。
- **Canvas：**760×220；上方旧响应 / 新标签两条输入线，下方三张公式项卡片，点击时突出对应连线。Canvas 不画不存在的数据处理层；DOM 显示完整方程 `L_total = λ_o L_old + L_new + R`。
- **反馈：**`L_old`：“把当前模型的旧任务响应拉向旧模型在同一新输入上的响应。”`L_new`：“把新任务输出拉向新任务真实标签。”`R`：“论文实验加入普通 weight decay；不是 LwF 的参数距离主项。”
- **证据 / 判断：**PDF p.4 式 (1)–(4)，p.5 总目标。读者能指出正则项 `R` 不等于蒸馏损失。
- **无障碍 / 边界：**公式有 HTML 文本副本；chips 保持焦点；选中态使用边框、图标和颜色。

### LWF-07 · 加大 `λ_o` 会怎样？

- **教学目标 / 模式：**Hybrid。把旧响应权重与新旧目标优先级联系起来，不伪造 accuracy 曲线。
- **初始状态与操作：**P1 滑杆范围 `0..2`、步长 `0.25`、默认 `1`。拖动或键盘调整立即更新公式系数、旧损失相对份额和反馈。
- **状态：**`lambdaOld:number=1`，取 9 个合法刻度。显示 `λ_o = x`，以 `λ_o/(λ_o+1)` 显示**仅是权重比示意**的条形，假定两项单位刻度一致；不要显示模型准确率。
- **Canvas：**760×200；一本中性色词典对应共享输入，两条平行箭头宽度代表系数相对权重；旧响应箭头随 λ 加粗，新标签箭头固定；橙色滑杆标记当前用户值。
- **反馈：**`0`：“旧响应项不加权；目标更偏新标签。”`0<x<1`：“旧任务约束较轻，参数适配空间较大。”`1`：“论文多数实验使用 λ_o=1。”`1<x≤2`：“旧响应项相对权重更大；这不等于旧准确率必然更高。”
- **证据 / 判断：**PDF p.5 及 Figure 7, pp.9–10。用户应看懂的是训练目标权重，而非保证的测量结果。
- **无障碍 / 边界：**range 的 aria-valuetext 读出权重和语义；保留明确文本“示意权重，不是性能曲线”；窄屏控制放在 Canvas 上下。

### LWF-08A · 点击参数区，追踪信息流

- **教学目标 / 模式：**Mathematical / technical。读者能区分共享层、旧任务头、新任务头，并知道 warm-up 后的更新范围。
- **初始状态与操作：**P5，默认选共享层；点击 DOM 节点按钮（不是只有 Canvas 热区）选择 `shared` / `oldHead` / `newHead`。
- **状态：**`selectedNode:'shared'|'oldHead'|'newHead'='shared'`。切换节点更新 Canvas 描边、有效路径、阶段角色和值得注意的参数事实。
- **Canvas：**760×260；节点坐标固定：输入→共享层→旧头 / 新头双分支。背景→无效路径→激活路径→节点。Canvas 内最多两个短标签；DOM chip 和固定详情面板展示长名称。
- **视觉反馈：**共享层选中显示到双头的蓝路径；旧头突出旧任务输出路径；新头突出新增 `θ_n` 路径。文字分别说明“共享给多个任务”“原任务输出参数，联合优化时可更新”“新任务新增分类权重”。
- **证据 / 判断：**Figure 2(e), PDF p.3；算法和方法，pp.4–5。选中节点必须改变路径，不是只弹 tooltip。
- **无障碍 / 边界：**三种 DOM button 提供键盘等价操作；焦点环明显；移动端纵排，固定详情区避免布局跳动；线型也区分活动状态。

### LWF-08B · 任务专属结构越多越好吗？

- **教学目标 / 模式：**Technical。将 Table 2(a) 消融中网络变体与 ImageNet→CUB 旧 / 新表现对应。
- **初始状态与操作：**P4 chips 切换六个原表配置：输出层（LwF）、last hidden layer、2nd last hidden layer、network expansion、expansion+LwF、fine-tuning with 10% `θ_s` learning rate。
- **状态：**`design` 为 enum，默认“输出层（本文）”。显示 Table 2(a) ImageNet old / CUB new 两个值；切换后改变专属区域轮廓与数值条。
- **Canvas：**760×250；固定共享底层与右侧 head 区；选项会改变着色范围 / 是否出现扩展节点；两根独立的 accuracy bar，旧 / 新任务分开，数值始终可见。
- **反馈：**原方案显示“LwF 在最终输出层；表内基线 54.7 / 57.7。”其他方案仅显示对应 Table 2(a) 值与“此任务对 / 此配置”，不输出全局优劣判断。注记：ImageNet validation + CUB test；论文原表原值。
- **证据 / 判断：**Table 2(a), PDF p.9。结果未显示额外专属层、expansion 或低学习率有一致优势；各配置表现有权衡。
- **无障碍 / 边界：**chip 键盘操作；`aria-live=polite` 更新名称、两个结果与 split；手机布局先图再数值表。不把其他表格的 delta 混进来。

### LWF-09 · 新输入离旧任务越远会怎样？

- **教学目标 / 模式：**Hybrid。以互动方式理解旧输出仅在新任务输入上被约束，远域软响应可能代表性不足。
- **初始状态与操作：**P6 在一个宽松 2D 示意区拖动“新样本”点，或按按钮“更接近 / 更远离 / 重置”。位置分三档：近、未知、远；无刻度、无连续相似度值。
- **状态：**`domainRelation:'near'|'unknown'|'far'='near'`。pointer 坐标仅映射三档，不代表距离量；同值由键盘按钮也可设置。
- **Canvas：**760×250；左区“旧域”由中性色云形标记；右 / 中区单一样本点；拖动会移动点并改变点线与关系文字，域团不动。近档绿色、未知蓝色、远档红色，并配形状或文本颜色外标志。
- **反馈：**近：“示意上新输入与旧任务更相近，旧模型响应可能提供更有用约束。”未知：“输入代表性不确定，不能据位置断言表现。”远：“示意上分布差异大，旧响应未必能保护旧域。”
- **证据 / 判断：**论文引言和讨论 pp.2, 7, 10；ImageNet→MNIST 与 CUB / Places365 观察。Canvas 永久标注“关系示意，无相似度量表”。
- **无障碍 / 边界：**拖动外提供三颗等价按钮；pointer 坐标换算到 intrinsic 区域并 clamp；键盘按钮能到达所有状态；触屏点击目标大；reduced-motion 下立即更新。

### LWF-10 · 一组结果说明什么？

- **教学目标 / 模式：**Technical，P8 用户启动结果赛。用同一协议看旧任务保存和新任务适配的权衡。
- **初始状态与操作：**图表为空、四行结果先显示短横线，`status='ready'`；用户点“开始比较”后四种方法每约 480ms 依次显现，点“重播结果”会重新播放。若 reduced motion，直接显示所有值。
- **数据 / 状态：**`status:'ready'|'running'|'done'`；数据固定：LwF `[54.7,57.7]`；fine-tuning `[50.9,57.0]`；feature extraction `[57.0,52.5]`；joint training `[55.3,56.6]`。其他绝对值按论文 Table 1(a) 相对 LwF 的差值换算。显示 %，一位小数。
- **Canvas：**760×300；左右分区 old ImageNet accuracy / new CUB accuracy；每方法同色成对短条；LwF 绿色，其余蓝 / 中性，fine-tuning 的旧任务劣化可辅以红边；用户开始后按方法依次展示，最后固定停留。只用一个图例 “旧 / 新” 放 DOM。
- **反馈 / 文字：**开始前“数据来自 ImageNet→CUB、AlexNet；条形尚未展开。”结束后：“该任务对中，LwF 比 fine-tuning 保留更多 ImageNet accuracy，CUB accuracy 也略高；feature extraction 保旧更好但新任务较低；joint training 用到了旧数据。”
- **证据 / 判断：**Table 1(a), PDF p.7；数据 split、metric、三次均值、delta 换算在固定 DOM 说明中完整呈现：ImageNet validation / CUB test；两者均 accuracy；baseline 绝对值为 `LwF + 原表有符号差值`。
- **无障碍 / 边界：**开始 / 重播 button 可键盘触达；Canvas 之外给等价 HTML 表格，`aria-live` 仅在完成时播报摘要；移动端图表纵向分组；不以奖杯暗示某法普遍最优；无需网络或外部图片。

## 三、可访问性与边界总表

- 所有操作由原生 `button` / `input type=range` 实现；Canvas 仅呈现，Canvas 热点均有 DOM 替代控件。
- 前置术语说明同时支持 hover、键盘和点击；说明在文档流中展开，不压住图表或正文；滚动、点到组外或 Escape 会收起。
- `:focus-visible` 轮廓清晰；按钮反馈、选中边框与语义颜色并用；不会仅靠红绿区分。
- `prefers-reduced-motion: reduce` 时跳过自动移动和数值插值；无持续闪烁；自动类比 Canvas 在离开视口时停止。
- 交互首选单栏移动布局；图宽 100%，手柄触区足够大，表格允许换行；没有必需横向拖拽。
- 失败、限制状态用事实语言表达；不由演示状态生成假准确率、推断通用胜负或重写论文结论。
