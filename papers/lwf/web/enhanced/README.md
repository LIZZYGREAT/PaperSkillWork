# LwF 交互式精读

这是 *Learning without Forgetting*（LwF）的简体中文交互式教程。内容以论文原文为依据，把“旧任务训练图像不可用时，如何加入新任务并尽量维持旧任务表现”拆成十章，逐步讲清数据路径、训练阶段、温度蒸馏、损失项、任务头结构、实验结果与适用边界。

## 本地预览

需要 Node.js 和 npm。在本目录运行：

```bash
npm install
npm run dev
```

终端会显示本地预览地址。生产构建使用 `npm run build`，构建后的静态文件位于 `dist/`；可用 `npm run preview` 本地查看构建结果。

## 教学路径

1. 从新旧任务的冲突出发，比较直接微调和 LwF。
2. 对比特征提取、微调、联合训练与 LwF 各自使用的数据和参数。
3. 追踪旧模型如何在新任务输入上生成旧任务软响应。
4. 逐步查看新头 warm-up 与联合优化时哪些参数会更新。
5. 调整温度，观察教学 logits 的软化；图中概率是示意值，不是论文测量。
6. 点选 `L_old`、`L_new` 和 weight decay `R`，辨认各自的监督信号。
7. 调整 `λ_o`，观察损失权重变化，而不是虚构性能曲线。
8. 查看共享层与任务头，并比较 Table 2(a) 的结构消融。
9. 拖动新输入或使用按钮，理解旧响应受输入代表性限制。
10. 展开 ImageNet→CUB 的 Table 1(a) 结果，并按任务对理解方法取舍。

全文采用“校订一本双语分类词典”作为教学类比。类比只帮助理解共享表示、任务输出和旧模型响应；它不属于论文算法。图示交互提供按钮或滑杆等 DOM 控件，Canvas 只承担视觉辅助。

十章的类比动效各自对应本章文字：从写入新词条、圈选路线，到标注旧响应、合并损失与核对结果；每段约 1 秒，只播放一次并停留在完整结果，滚出视口会暂停，系统启用减少动态效果时直接显示终态。第 1 章对照约 1.8 秒，可重播或重置；第 10 章每约半秒揭示一种方法，四行结果完成后保持可见。每章交互模块上方的术语可悬停、键盘聚焦或点击查看解释，解释在原位展开并推动图表下移，不遮住内容；点到别处、滚动或按 Escape 会收起。

## 证据与数值说明

- 核心来源是 [本地论文 PDF](../../source/paper.pdf) 与 [arXiv 版本](https://arxiv.org/abs/1606.09282)。逐项主张、页码、表格和限制见本项目 `research/01_review.md`、`research/02_evidence_audit.md`。
- Table 1(a) 的 LwF 原值是 ImageNet 54.7%、CUB 57.7%。同表其他方法以“相对 LwF 的有符号差值”报告；结果交互将原表差值换算成绝对值，并在界面标明该换算。协议为 ImageNet validation / CUB test，指标为 accuracy，报告三次运行均值。
- Table 2(a) 的六个结构对照显示原表 ImageNet 与 CUB accuracy，限定于该任务对、AlexNet 和对应配置。
- 教学 logits、损失权重图、输入域关系图和遗忘示意均不是论文测量值。教程不会把 LwF 描述成 replay、零遗忘保证或已验证的大模型方案。
- 相关延伸视频如有展示，标题会注明它是持续语义分割后续工作，不是 2016 年 LwF 原论文讲解。
