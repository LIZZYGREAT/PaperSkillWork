R1 · A资产样张

五组对象，先各自长大，再谈编排

样张按真实尺寸绘制，不是缩略示意图。网络、样本、响应坐标、冻结目标、记忆槽各自有固定材质与比例；页面缝合时不重新发明。

网络不再是三块斜板

三层节点列 + 稀疏层间连线，平面、无透视、无虚构激活值。模型卡只有一张：结构、位置、尺寸在更新前后完全不变。

  • 前向：列级高亮带 + 连线转绿，表示焦点传递，不画游走箭头。
  • 更新：只有虚线外环 + θ 标签变色 + 顶部参数端口，一个信号就够。
  • 输入 / 输出 / 参数是三个不同端口，位置固定。

样本只留身份，视图只是临时

原图是留存的图卡，增强视图是带裁剪角标的小卡；两者像素相同但外观不同，运动中不会误读成三张图。

  • 记录里只用缩略图作身份引用，不再重复整张图。
  • 标签 y 永远在图像之外：虚线框 + “独立监督”。
  • 未来样本 x₂ 换个纹理，一眼可区分先后。

响应坐标：一个刻度尺，三个读数

顶部一条 0·1·2 的刻度轴，三条水平轨道共享同一尺度；实心圆是当前输出，数值贴在标记右侧，0 也留在轴上。

  • 冻结副本是空心方块，同形、同坐标、不同填充。
  • 比较阶段直接把方块搬到圆点旁，差值用括号量出来。
  • 平方贡献是真实方块面积，零项退化成一条线。

记忆是平面容器，不是透视托盘

两个 340×108 的槽位并排，槽号贴在槽上沿；记录 324×104 内嵌 8px 边距，尺寸真实匹配，不做缩放。

  • N 计数独立成列，只在合法写入时 0 → 1。
  • 记录 = 原图缩略 + 冻结数值块（斜纹虚线，明确不更新）。
  • 读取时记录不动，只多一个读出引用。

一条损失通道，三列舞台，一条记忆带

1120×640 的舞台分成可预期的几个区：顶部损失通道、左侧数据、中部唯一网络、右侧唯一响应坐标、底部记忆带。参考线标出实际比例，避免实现时又缩成一张全景小图。

R2五张高保真关键帧

每一帧都回答：上一阶段留下了什么

五帧共享同一套对象、同一坐标与同一材质，但每帧重新组织主次：复制时看响应下方，写入时看槽位，比较时把镜头让给坐标。下面每帧都附“必须直接看出的信息”和“运动与交接”，供 R3 实现对照。

F1 · 前向与响应 · 第 i 步 更新之前

一个输入，长出整组判断

样本进入唯一当前网络，三类 logit 逐类形成；标签 y 在图像之外，属于另一条监督关系。

必须直接看出

  • 一张图产生的是整组三个分数，不只一个类别答案。
  • 标签 y₁ = 猫 是虚线框，独立于图像与记录。
  • θ 标签仍是 θᵢ，CE 上写着“未反传”。

运动

视图从原图右侧沿弧线进入左输入端口；网络列级高亮从左向右传递；三条轨道依次长出实心圆，数值贴在标记右侧；最后 CE 节点与标签框就位。

交接

三个圆点停在原坐标不动——它们是下一帧复制动作的起点。视图停在轨道起点上方，不再移动。

F2 · 复制与冻结 · 同一时刻

源输出留下，数值副本独立出来

在相同坐标复制出空心方块，再让它离开响应轨成为冻结块；网络与 θ 完全没动。

必须直接看出

  • 方块与圆点同坐标、同数值，只是形状不同。
  • 源圆点仍在原处，副本有自己的载体（虚线 + 斜纹）。
  • θ 未变，所以“冻结”不是模型停止学习。

运动

方块先在圆点位置以零位移描边，然后整组向右下移动约 90px 进入冻结块；块边框由虚线补齐，斜纹淡入。全程网络、轨道刻度、数值都不变。

交接

冻结块停在响应下方。下一帧它要和原图缩略图合并成一条记录——两者尺寸已经匹配，不需要缩放。

F3 · 更新后写入 · 第 i 步结束

先更新网络，再把候选放进空槽

一条梯度虚线进入参数端口，θᵢ → θᵢ₊₁；随后记录写入 slot 0，N 从 0 变 1。

必须直接看出

  • 更新只有一条路径（∇θ），发生在写入之前。
  • 记录 = 原图缩略 + 冻结块，尺寸正好放进槽。
  • 响应轨变淡：本步不重算新输出，不编造优化后数值。

运动

CE 沿虚线向模型顶部端口发出一次脉冲 → 模型外环亮起、θ 标签变为 θᵢ₊₁ → 缩略图从数据列滑下与冻结块合拢成记录 → 记录沿短弧落入空槽 → N 由 0 翻到 1，槽号旁出现“刚写入”。

交接

记录留在槽内，N=1；模型保持更新后状态。下一帧从这条记录读取，而不是重新造一份。

F4 · 未来回放 · 第 j = i+1 步

后来，回放从这份记忆真实出发

下一步先采样既有记录：槽内记录不动，读出引用重新增强后进入同一模型，得到由当前参数计算的新输出 aⱼ。

必须直接看出

  • 回放有可追踪的来源：槽 0 标着“读取中”，读出视图从槽左缘出发。
  • 两个输入端口不同：上方是当前 x₂，下方是回放 x₁@i。
  • θ 已变为 θⱼ，新输出 aⱼ 由当前参数计算。

运动

x₂ 从上方沿弧线进入当前输入端口；槽内记录出现一圈虚线“读出轮廓” → 视图沿左侧通道上移 → 模型第二次前向 → 回放轨道逐类长出 (1,2,0)；记录与槽号始终不动。

交接

冻结方块还在记录里。下一帧它们会被搬到同一坐标，与新的圆点直接比较。

F5 · 匹配与联合更新 · 同一步

差异变成贡献，然后只更新一次

同一坐标比较、差值平方求和得到 L_dark = 2；它与当前 CE 合并后只产生一次参数更新，记忆不变。

必须直接看出

  • 比较在同一类别坐标、同一尺度上完成，方块 = 冻结值。
  • 差值 → 平方 → 1+1+0=2，与公式一一对应。
  • 两条损失汇入一次更新；记录、z₁、N 都不变，未写 x₂。

运动

镜头把比较区放到主位，模型缩为左侧锚点；三个方块从记录中被“取出”并沿轨道滑到对应圆点旁 → 差值括号张开 → 平方块按 |d| 生成 → 求和 → 与 CE 汇入联合损失 → 一条 ∇θ 进入模型锚点。

交接

停在“尚未写入 x₂ 候选”。下一单元从这里接着讲记忆怎样在某条候选到来时被选中或被替换。

R1 · C复用判定

每一类对象，为什么这样画

按 Kit 的“直接复用 / 组合并适配 / 借鉴成熟设计重绘 / 完全独立实现”逐一判定，记录原因与最终归属，避免又滑向“全部手写”或“全部拼 Kit”。

对象判定原因与归属
网络借鉴重绘参考 MiniNetworkGlyph 的“层列 + 节点 + 稀疏连线”设计经验，但舞台需要在一张卡内表达前向焦点与参数更新端口，DOM 组件无法在 SVG 舞台内随镜头移动。DER 自绘，保留 Kit 的节点配色与语义高亮规则。
样本 / 视图借鉴重绘沿用 SampleToken 的像素网格与卡片材质；增加“裁剪角标”区分临时视图。记录里的缩略图是同一像素网格的缩尺版，属于 DER 记录卡的一部分。
响应坐标独立实现需要“同坐标、可比较、可分离”的轨道语义，ResponseMeter 的水平条无法承载方块分离与差值平方。复用其正/负填充与描边配对规则。
冻结目标组合适配形状/虚线/斜纹来自 Kit 的 frozen 角色（data-state="frozen"）；数值块是 DER 记录卡的内部结构，不另造公共组件。
记忆槽独立实现K=2 的固定容量、槽号、记录尺寸匹配属于 DER 舞台几何，不是通用列表；不升级成公共资产。
播放器直接复用useAnimationTimeline + SceneTransport 已验证暂停/回退/重播/键盘/reduced-motion；只改舞台与文案，不重建第二套播放器。
公式直接复用舞台外的 Ldark 用真实 MathML；图内只放短符号与数值，避免 SVG 里的伪公式。
